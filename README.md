# Size of a hydrogen plasma controls methane conversion in its afterglow

Data and code to reproduce all figures of:

> M.D. Ruijzendaal, M.L. Azevedo, J. Vargas, M. Arboleda Rodallega, T.D. Butterworth,
> G.J. van Rooij, P. Diomede and N. den Harder, "Size of a hydrogen plasma controls methane
> conversion in its afterglow", in preparation (2026).

## Quick start

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then run

```bash
uv run reproduce.py
```

uv installs Python 3.13 and the exact package versions in `uv.lock` into a local `.venv`, so the
results do not depend on what is already installed on your machine. Figures are written to
`output/` (about 30 s).

Without uv, use Python 3.13 and a virtual environment:

```bash
python3.13 -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install .
python reproduce.py
```

This installs the pinned direct dependencies from `pyproject.toml`, but not the exact versions of
indirect ones.

To work with the scripts interactively, open them in VS Code: the `# %%` markers make them run
cell by cell, like a notebook. Select the `.venv` interpreter.

## Re-running the plasma chemistry model

Figure 10 uses the stored model results in `data/model/neutral_vs_charged_chemistry.csv`, so
the model does not need to be run to reproduce the figures. To re-run it:

```bash
uv run reproduce.py --model
```

This takes about 1 minute on a 12-core laptop, and writes to `output/model/` so that it does not
overwrite the stored results.

**Chemistry set.** For the neutral H/H2 chemistry, the results in the paper were obtained with
the chemistry set of Wang et al. ([Fuel 387, 134407, 2025](https://doi.org/10.1016/j.fuel.2025.134407)).
Its license does not allow redistribution, so it is not included here. Without it, the model
uses the H/H2 reactions of GRI-Mech 3.0, which is included with Cantera; the H mole fractions
then differ by up to 1.4 percentage points from those in the paper, and the cases at 4473 K do
not converge. With the chemistry set of the paper, a re-run reproduces the stored results
exactly. To use the chemistry set of the paper, obtain `DLR_3.yaml` from
its authors and place it in `mechanism/` (see `mechanism/README.md`). Output files are labeled
with the chemistry set used (`_DLR_3` or `_gri30`).

## Reproduction of the figures in the paper

All figures were compared pixel by pixel (at 150 dpi) with the PDFs in the LaTeX source of the
paper. Figures 2, 3, 5a, 7, 8, 9 and 11 are identical (at most 0.1% of the pixels differ, from
anti-aliasing). The remaining differences:

- **Fig. 4**: the grey line and label "1 slm, 100 cm³" were added with code that was not
  saved. They are reconstructed here: the line is the rate of 1 slm (at 273.15 K and 1 atm) in
  100 cm³, which agrees with its position in the paper to within a pixel at 1200 dpi; the label
  positions were measured from the paper. Remaining differences are anti-aliasing in the
  legends (0.3% of the pixels).
- **Fig. 5b**: the version in the paper was made one day before the stored results (18 versus
  19 June 2026), with a slightly different color scale (0.7% of the pixels). The figure made from
  the stored results is identical to the one made by the original analysis on 19 June.
- **Fig. 10**: the model results agree (the curves overlap); the figure in the paper was
  made with matplotlib 3.11.1 instead of 3.10, which draws the dotted legend handle and the axes
  slightly differently (4.5% of the pixels).

The figures were made over ten months with an unreleased version of the plotting style
([wedme-plots](https://github.com/mruijzendaal/wedme-plots)), whose label padding changed in that
time; each figure script sets the value that was used for the figure in the paper.

Things to be aware of when reading the paper:
- The caption of Fig. 7 says the error bars are 2σ. For the conversion (7a) this is the case;
  for the temperature (7b), and in Fig. 11a, they are 3σ of the fit, as in Fig. 2.
- The filenames of the 2D measurements (Figs. 5 and 9) give 850 or 900 W; their captions say
  1000 W.
